# Tactical How-To Template

## Structure

```
[HOOK — what you'll teach and why it matters, in one punchy line]

[Context — the problem this solves, in 1-2 sentences]

Here's how to do it:

→ Step 1: [Action]
[Brief explanation]

→ Step 2: [Action]
[Brief explanation]

→ Step 3: [Action]
[Brief explanation]

[Result — what this looks like when done right]

[CTA — invite readers to try it or share their approach]

#hashtag1 #hashtag2 #hashtag3
```

## Example

```
You can connect any API to your database in under 10 minutes with n8n. No SDK. No boilerplate.

Most developers still write custom integration scripts for things that should take minutes. Here's the exact workflow:

→ Step 1: Set up an n8n webhook trigger
Point it at the endpoint you want to listen to. One node, zero config files.

→ Step 2: Add a Function node for transformation
Map the incoming payload to your schema. 5-10 lines of JS, tops.

→ Step 3: Connect your database node
Postgres, MongoDB, MySQL — pick your flavor. n8n handles the connection pooling.

→ Step 4: Add error handling
One IF node + one Slack notification. Your future self will thank you.

Total build time: 8 minutes. Total maintenance since deployment: 0 hours.

What integration are you still handling with custom code that could be a workflow?

#n8n #APIntegration #FullStackDev #stacx24
```

## Tips
- Keep steps to 3-5 (more than that and readers lose interest)
- Each step should be actionable and specific
- Include the "result" to show what success looks like
- Time/effort metrics make these posts highly saveable
