I use beads heavily. But I kept losing track of what the agent was actually doing.

Terminal output scrolls by fast. Context disappears. I'd come back to a project after a few hours and think: "Wait, what was this task even about?"

Managing 2-3 active projects made it worse. Each repo had its own beads tasks running, and my brain was the only "dashboard."

Then I found beads-ui.

One command: `bdui start`. That's it.

Suddenly I had a kanban board showing every task across all my projects. No more digging through terminal history. No more "which repo was that in?" moments.

→ Real-time sync — no manual refresh
